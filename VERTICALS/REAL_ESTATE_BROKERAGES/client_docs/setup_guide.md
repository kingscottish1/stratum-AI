# Real Estate Vertical — Client Setup Guide

Go-live target: **10-14 days** from signed contract to first live lead handled.

## Phase 0 — Kickoff (Day 0-1)
- Scope call: lead sources (portal, website, SMS, phone), team size, CRMs
- Confirm MLS + CRM access list (see mls_integration_guide.md)
- Decide response SLA: hot leads < 5 min, warm < 1 h (AI covers nights/weekends)

## Phase 1 — Integrations (Day 1-6)
1. **CRM**: Follow Up Boss (typical) or your CRM via REST — leads, activities, deals.
2. **MLS**: RESO Web API credentials from your MLS board (or IDX feed).
3. **Calendar**: agent Google/Outlook calendars for showing slots.
4. **Channels**: Twilio number for SMS/WhatsApp; email domain verified.

## Phase 2 — Tuning (Day 6-10)
- We replay your last 100 leads through the qualifier and calibrate scoring.
- Draft and approve message copy (templates/ folder).
- Test: SMS booking, reschedule, "are you available Sunday?" edge cases.

## Phase 3 — Shadow + Live (Day 10-14)
- Shadow: agent gets Slack card for every AI action for 48h.
- Live: hot leads auto-alert + auto-book viewings (configurable).
- Weekly dashboard: reply speed, qualification accuracy, showings booked.

## Ongoing
- Monthly tune: scoring calibration against actual closings.
- Quarterly review: pipeline value generated by AI vs baseline.
