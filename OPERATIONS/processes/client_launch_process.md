# Client Launch Process (the 14-day playbook)

## Day 0 — Kickoff
- [ ] Contract + NDA + DPA signed (checklist stage 1)
- [ ] Client folder created from _TEMPLATE_new_client/
- [ ] Kickoff call: scope, access, success metrics, copy approver

## Day 1-3 — Access & integration
- [ ] Credentials in (encrypted) · discovery sheet completed
- [ ] Integration build starts (calendar/PMS/CRM/TMS per vertical)
- [ ] Test channel live (Twilio number)

## Day 4-7 — Build & replay
- [ ] Agents configured per config.yaml
- [ ] Historical replay (50-100 conversations / 200 invoices) — accuracy report
- [ ] Copy approved (SMS/email/voice templates)

## Day 8-10 — Shadow mode
- [ ] AI live in shadow (recommendations only)
- [ ] Client team trained on dashboard + Slack handoffs
- [ ] Go/no-go meeting

## Day 11-14 — Go live
- [ ] Auto-mode on (per client config: auto-book / confirm-first)
- [ ] Monitoring alerts armed · weekly report scheduled
- [ ] deployment_status.md → LIVE · clients_database.xlsx updated

## Day 30 — First business review
- [ ] Metrics vs baseline · wins & issues · expansion conversation starts
- [ ] Handover to Account Manager

**Exit criteria:** client says "it works" + accuracy ≥ 95% on replay + no P1s open.
