# Client Invoicing — Template & Process

## Invoice structure (monthly, net 30)
1. Platform fee (tier per SOW)
2. Add-ons (voice AI, extra locations, seats)
3. Usage overage (if contract has limits — rare, needs pre-approval)
4. One-time items (new integrations, custom work — quoted first)

## Process
1. 1st of month: billing run from clients_database.xlsx (MRR + add-ons)
2. 2nd: invoices sent via billing tool (Stripe/QuickBooks/Xero)
3. 15th: reminders for overdue; 25th: pause non-paying instances
   (with 7-day grace + personal call first)
4. Every invoice: link to SOW + supporting usage report

## Fields required on every invoice
Client legal name · billing contact · PO number (if client requires) ·
invoice date · period · line items with descriptions · payment terms ·
late fee policy · VAT/tax handling per jurisdiction.
